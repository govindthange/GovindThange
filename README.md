### 🚀 Highlighted Repositories

* ☁️ [**local-aws-kit**](https://github.com/govindthange/local-aws-kit) - I created this solution to host and run commonly used AWS services locally using docker, Kubernetes/KinD/k3s and Terraform. This setup is built with around 2 dozen containerized services to simulate around 70 AWS services locally. However, only half a dozen AWS services have been tested so far.

* 📈 [**woodwind**](https://github.com/govindthange/woodwind) - Using pine script I built a technical indicator for TradingView platform. It is focused on technical analysis, strategy configuration, and smarter stop-loss for placing trades. It is centered around Ichimoku-style trend, breakout, and risk-management logic. It includes a strategy playbook and supporting utilities for equilibrium calculations, trade execution rules, and portfolio-level P&L analysis. The framework is designed to simulate entries, exits, stop placement, and scaling behavior across long and short positions. It emphasizes confluence-based decision making, including Kumo bias, TK cross checks, and lagging-span safety filters. This project is best understood as a research-and-backtesting toolkit for algorithmic market strategies rather than a general-purpose application. I tested it with over 4000 virtual trades.

* **♞** [**de-knight** `(dev branch)`](https://github.com/govindthange/de-knight/tree/dev) - Here, I laid the groundwork for a blockchain-based, open-source project designed to be entirely community-driven. It is envisaged as a play-to-earn game that demonstrates a crowdfunding ecosystem, facilitating crypto payments, DeFi mechanisms, and NFT-backed campaign rewards - all governed via DAO voting on the blockchain. The platform utilizes advanced Web3 concepts such as non-fungible tokens (NFTs), escrow mechanism, multi-signature wallets, decentralized governance, and Oracles. Players can earn revenue by trading in-game NFTs on open markets, as well as by collecting cryptocurrencies and native digital assets.

* 🧮 [**ml-gallery**](https://github.com/govindthange/ml-gallery) - Here, I created mutiple ready-to-use ML PoCs to accelerate setup across popular models and frameworks. This helps me quickly jumpstart projects with reusable easy starting points for Python, JavaScript, and related ML tooling.
  - One template uses NLP Named Entity Recognition (NER) training with spaCy pipelines and custom model tuning for domain-specific entity extraction.
  - GPT-KIT is a PoC to demonstrated use of local LLM w/ LangChain, semantic embeddings, vector database indexing, and RAG for document Q&A.

* 🧪 [**ml-playground** `(dev branch)`](https://github.com/govindthange/ml-playground/tree/dev) -  It is a hands-on collection of several AI/ML **PoCs with full-stack containerized deployment** and focused on practical use cases. It includes K-means **clustering** (customer segmentation), **logistic regression** (customer attrition, account closure, EMI default, fraud detection), **linear regression** (credit card usage, employee compensation), and **predictive analytics** w/ exponential smoothing with seasonality (bank's locker demand forecasting) across banking, finance, and forecasting scenarios. It is built with Jupyter, Streamlit, and Docker for rapid experimentation and deployment.

* 🤖 [**agentic-email-crew**](https://github.com/govindthange/agentic-email-crew) - I receive over 280-300 emails on daily basis and its hard to read and keep track of these emails. Its an agentic AI solution I created for automating my email processing by sorting and creating insightful mind map based summary.

* 🛠️ [**kit**](https://github.com/govindthange/kit) - Here I created an exhaustive collection of over 14 ready-to-use starter templates for rapidly setting up projects across modern platforms, infrastructure, and developer workflows. It includes high-level stacks for Kubernetes/Helm, Docker, Ansible, Jenkins, Ethereum/Truffle kit for DeFi workspace, Java / Spring Boot, Python, OCR, networking, and GenAI/LangChain-based app templates, making it a practical accelerator for building and deploying diverse tech solutions.
